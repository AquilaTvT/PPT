# 参考片「千本樱」"像素感"渲染取证（Study F）

素材：`/tmp/claude-0/ref/senbon.mp4`（H.264 High，1920×1080，30 fps，7573 帧，yuv420p BT.709 limited，约 4.05 Mbps）+ 91 张镜头关键帧 `/tmp/claude-0/ref/shotkeys/`。
脚本、裁切图、中间数据：`/tmp/claude-0/ref/forensics/`（`scripts/`、`crops/`、`out/`）。

## 0. 结论先行（TL;DR）

1. **没有像素网格。** 91/91 张关键帧以及全片 7573 帧都按原生 1920×1080 渲染、带抗锯齿，**没有**低分辨率内部渲染，**没有**最近邻放大。可检测的块尺寸 = 1 px。字幕、角色、2D、3D、粒子各层都一样，没有哪一层用了独立的像素网格。
2. 所谓"像素感"，实际来自**印刷网点（screentone / Ben-Day 半调）**：59/89 张关键帧里有规则的 2D 圆点阵，点距中位 **7.06 px**（多数 7.0–7.1，少量 8–9），常见 45°，也有 15°、30°、0° 或交错排列。圆点柔边、直径约 3–4 px，调制当地亮度 ±3.5–21%（最强 ±54%）。网点**属于各自图层**，随图层平移和视差，不是锁在屏幕上的蒙版。此外还有 AM 半调光晕（点的大小或覆盖率随光强变化）、3D 城市的点阵灯光、纸纹和颗粒。
3. **配色是平涂设计色，不是全局限色调色板。** 每帧有效色数中位 24（CIELAB k-means 达到 ΔE≤2.5 所需的 k），一套 64 色全局调色板的拟合误差是逐帧调色板的 1.73 倍。整体是暗调：帧亮度 L* 中位 14.2，黑位偏暖紫（最暗约 #18100f），高光为米黄纸色（约 #e7dac3），不出现纯黑和纯白。
4. **不抖动。** 没有 Bayer，也看不到误差扩散。渐变要么做成平涂色带（台阶式），要么用半调网点表现。
5. **后期：** 无扫描线，无 CRT 弯曲，无色差（RGB 通道错位 0.00 px），无全局 bloom（光晕是逐个元素设计的）。实际存在的有：细颗粒和纸纹（只在亮度通道），暗角（角落约 −22%），以及**整帧"片门抖动"**——每 2–3 帧随机跳到一个新偏移（跳幅中位 0.92 px），伴随阶梯式亮度闪烁。
6. **运动是亚像素的，没有网格锁定。** 例如镜头 45 前景每帧 −9.508 px，只有 1% 的边缘位移落在整数附近；同一镜头多层视差，天空 0、中景 −2.07、前景约 −10 px/帧。
7. **字幕**是平滑抗锯齿的粗明朝体竖排：主歌词字高约 80–115 px，引导小字约 30–45 px，标题 130–330 px。常用米白字 + 2–4 px 深色描线 + 向右下偏移约 7 px 的暗红阴影。
8. **AI 角色图**和其他层在同一原生网格上，没有像素化。处理方式是平涂赛璐璐（脸部有效色约 12–24）+ 贴纸式描边（1–2 px 深线 + 约 4–5 px 浅粉/米色边 + 外侧暗红线），阴影里加网点；很多镜头直接用深色剪影 + 2–3 px 金色或米色描边。

> 对美术组的含义：如果 MV-B 要做真正的像素画（低分辨率 + 最近邻 + 限色），那是**偏离**参考片风格，需要客户确认。要"复刻"参考片，应该复刻的是"复古印刷网点 + 纸 + 胶片抖动"的质感。

## 1. 方法与校准

- **取样：** 用 ffmpeg 输出 rawvideo yuv420p，不做任何缩放，直接分析原生 Y 平面。关键帧 PNG 与 ffmpeg 按 BT.709 解码的第 n 帧逐像素一致（MAE 0.0）。`-ss n/30` 的输入定位也逐帧核对过，是精确的。
- **阳性/阴性对照：** 取 3 张关键帧（k01018、k04448、k03545），分别做成：
  - 最近邻像素画：块尺寸 B=2/3/4/6/8；
  - 双线性低分放大：1280→1080、960→1080；
  - 8/16/32 色色调分离；
  - 4×4 Bayer 抖动；
  - Floyd–Steinberg 16/32 色。
  
  全部经 x264 CRF 23 和 CRF 30 编码后，用与参考片完全相同的指标测一遍，用来确定阈值。
- **网格指标 S(B)：** 先找出 |ΔY|>8 的强台阶，统计它们的能量有多少集中在"列号 mod B"的同一相位上，归一化后 0 表示无网格，1 表示完美的最近邻网格。另有两项辅助：相邻强台阶间距为 1 px 的比例（gap1），以及强边缘 10–90% 的上升宽度。
- **局限：** 4.05 Mbps 的 4:2:0 编码会抹掉部分细颗粒，色度也只有半分辨率。所以下文的颗粒和噪声幅度都是**编码后**的数值；复刻时，编码前的强度要略高一些。

  对照：真 8/16/32 色图经 x264 后，k_eff 分别为 6–8 / 12–16 / 12–24。

## 4. 抖动（Q3）与网点

**抖动：没有。**

- **Bayer 检验：** 对角线频率 (¼,¼) 和 (½,½) 的谱峰（相对邻域背景的倍数）如下。参考片最大值比 Bayer 对照低 1–2 个数量级。

  | 样本 | (¼,¼) | (½,½) | 平滑区 1 px 高频噪声 |
  |---|---|---|---|
  | Bayer 对照 | 242–1794× | 184–894× | 9.8–28.8 |
  | FS 对照 | 0.1–2.5× | 0.8–3.6× | 0.96–2.50 |
  | 原生对照 | 1.2–1.5× | 0–0.2× | 0.93–2.38 |
  | **参考片** | 中位 1.1×，最大 6.9× | 中位 1.1×，最大 10.9× | 中位 2.07（最大 7.83 在网点很重的 k02415） |

  轴向 ¼、½ 频率上的峰在原生对照里也有（编码伪影）；参考片里的轴向峰逐一追查，来自竖栏杆和铁笼栏（k01991、k03884，`crops/k01991_*_s6.png`），不是抖动。
- **误差扩散：** 平滑区噪声与原生对照处在同一水平，没有证据。
- **渐变的实际做法：**
  - **平涂色带。** k02034 的夜空连续 230 行 Y≡32，然后跳一阶进入红色地平线带，没有任何过渡噪声。
  - **AM 半调。** k02455 月亮光晕在 r=80–110 px 处亮点覆盖率 0.80，到 r=380–410 px 降到 0.06，点本身亮度基本不变（`crops/k02455_1050_150_400x300_s1.png`）。k00328 路灯的光晕由直径约 20 px 的圆点组成。

**规则网点（这才是"像素感"的来源）**

- **普查方法：** 每帧取 12 个 512² 窗口做 2D FFT，要求在 5.5–9.5 px 周期段出现**两组角度相差 ≥40°、周期相近**的强峰（单向线条不算）。阈值 200× 下，6 张无网点帧的 72 个窗口零误报。
- **覆盖面：** 59/89 张关键帧检出网点（阈值翻倍到 400× 仍有 52/89）；23 张关键帧至少一半窗口带网点。
- **周期：** 中位 7.06 px（p10 6.63，p90 9.07）。
- **角度族：**

  | 排布 | 关键帧数 |
  |---|---|
  | 45°/135°（正方点阵转 45°，最近邻点距 7.0 px） | 14 |
  | 15°/105° | 11 |
  | 0°/90° | 约 10 |
  | 交错排列（行距 7.1 px、行内 7.0 px、隔行错半格；频谱上表现为 90° 7.01 px + ±26.3° 6.29 px，表中记作 6.7px@90°/26°） | 9 |
  | 30°/120° | 6 |
  | 其他 / 透视变形 | 9 |

- **点形与强度：** 柔边圆点，直径约 3–4 px。调制深度通常是当地均值的 ±3.5–21%（2–11 Y 级）；k02415 夜街达到 ±54%（24.8 Y 级），整帧像 LED 点阵（`crops/k02415_760_560_120x90_s6.png`、`crops/dots_6x.png`）。
- **网点随图层运动：**

  | 镜头 | 网点位移（px/帧） | 内容位移（px/帧） |
  |---|---|---|
  | 6（k00328） | −11.02 / −10.92 / −10.89 | −10.98 / −10.88 / −10.94 |
  | 33（k01871） | +4.99 / +5.06 | +4.96 / +5.04 |

  也就是说，网点是图层的填充纹理，会随图层旋转和视差，不是屏幕空间蒙版。

  | 20 | −31.82 / −31.79 px | — |

  结论：**所有运动都是平滑亚像素渲染，没有整数吸附，更没有按块吸附。** 不存在像素网格，也就谈不上锁定；网点和纹理随所在图层亚像素移动；最后整帧再叠加约 0.9 px 的阶梯式抖动。

- **镜头运动统计（90 个镜头）：** 全局平移中位 1.40 px/帧；56 个镜头 >1 px/帧，24 个 >3，11 个 >5（最快约 38 px/帧，k04504 甩镜）；60% 的帧位于平移 >1 px/帧的镜头里。逐镜头数据见附表。

## 9. 复刻配方（Remotion + Blender）

1. **画布：** 1920×1080、30 fps，**原生分辨率渲染**。不要 `image-rendering: pixelated`，不要低分辨率放大，位置不要取整（保持亚像素 transform）。3D 也直接渲 1080p，景深和运动模糊可以保留。
2. **配色：**
   - 每场景 12–32 个平涂色，取自主色谱：
     - 暖黑 #18100f / 紫黑 #23171f / 梅紫 #3d252f / 褐黑 #271b17；
     - 纸 #e7dac3 / #d5c3a7；
     - 靛 #36436f / #272c4c / #17192e；
     - 金 #bb9448 / #d4b677；
     - 樱 #db9ca3 / #e6c2c4；
     - 朱 #a7272e / #721c26；
     - 发绿 #1f2616。
   - 不出现纯黑或纯白：最暗约 RGB(13,4,0)，最亮约 (251,228,219)。
   - 目标统计：暗部偏紫（a*≈+6），亮部偏暖（b*≈+11），平均 C*≈12，帧中位 L*≈14。
3. **渐变：** 用平涂色带，或用半调网点，不做平滑渐变。不加 Bayer 或误差扩散。
4. **网点（核心质感）：**
   - 正方点阵，最近邻点距 7.0–7.1 px（变体 8–9 px），默认转 45°；也可用 15°、30°、0°，或交错行（行内 7.0、行距 7.1、错半格）。
   - 柔边圆点直径约 3–4 px，亮度调制 ±10–20%（重点镜头可到 ±50%）。
   - **作为图层填充**，随图层移动和视差。CSS 写法示例：两层 `radial-gradient(circle, rgba(255,240,220,.18) 1.6px, transparent 2.2px)`，`background-size: 9.9px 9.9px`，第二层偏移 `4.95px 4.95px`，就得到 45° 点距 7.0 px；需要其他角度时再整体 `rotate()`。
   - 光晕用 AM 半调：点距 9–20 px，覆盖率从光源处约 80% 降到约 300 px 外约 5%。
5. **纸 + 颗粒：** 一张固定的纸纹 / 颗粒贴图（斑驳 + 纤维，颗粒约 1–3 px，只作用于亮度），编码前强度约 ±2–4%（编码后实测 σ≈0.4–1.6 Y 级）。贴图不要逐帧重生成，让它跟着片门抖动一起动。
6. **暗角：** 正片叠底；从半对角线约 0.55 处开始近线性衰减，到角落约 ×0.77。
7. **片门抖动 + 闪烁（最后对整帧施加，包括字幕）：**
   - 每 2–3 帧（随机，偶尔 5 帧）跳到一个新的随机偏移，跳幅 0.6–1.6 px（中位约 0.9 px）；两次跳动之间保持不动，不做插值。
   - 同一时刻做阶梯式亮度闪烁 ±0.5–1.5%。
8. **不要加：** 扫描线、CRT 弯曲、色差、全局 bloom。光晕逐个元素做：月亮用约 8 px 硬边 + 约 70–100 px 半径、+15…+28 Y 级的弱晕；灯用小柔核 + 网点场。速度感可以用色版错位残影（红/绿副本错开 15–90 px）。
9. **运动：** 30 fps 连续亚像素运动，多层视差（例如远景 0、中景 −2、前景 −10 px/帧），花瓣粒子持续飘落，近景花瓣加景深模糊。只在标题卡和片尾卡上做静止停顿。
10. **字幕：** 竖排粗明朝体（例如 Shippori Mincho B1 ExtraBold、Zen Old Mincho Black、Noto Serif JP Black 一类）。
    - 主字约 100 px（80–115），引导字约 40 px，强调字 150–230 px。
    - 样式：米白 #ebe2d3 + 2–4 px 深褐描线 + 暗红 #6d2d2e 偏移阴影（向右下 +7/+7 px）；复杂背景改用深字 + 8–10 px 米白描边。
    - 主列放在 x≈1660–1780，首字 y≈160。
11. **角色：**
    - AI 图先压成平涂赛璐璐（约 12–24 色阶，不抖动、不像素化）。
    - 抠图加贴纸边：1–2 px 深线 + 4–5 px 浅粉 / 米色 + 外侧暗红细线；或做成剪影：#17100d + 2–3 px 金边 #ba9d64。
    - 阴影里铺网点，按原生分辨率合成，并放在全局颗粒、暗角、抖动之下。
