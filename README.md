## 教材版本说明

- 本课属于人美版（2024）全国版五年级上册（黄宗贤主编，人民美术出版社2026年7月第1版，ISBN 978-7-102-08964-5）。目录中第四单元《装点节日》共三课：农民画里的节日（第34页）、巧夺天工的民艺（第37页）、聚合至美庆佳节（第41页）。
- 人教版（2024）五年级上册第四单元是《数字时代——探索数字媒体艺术》，没有农民画这一课；人美版北京版五年级上册目录里也没有农民画这一课。

## 课件使用提示

- 字体用的是 Windows 自带的“微软雅黑”。封面、章节页的书法标题是图片（马善政毛笔楷书，SIL OFL 开源字体），在任何电脑上显示都一样。
- 全篇用“平滑”切换（PowerPoint 2019/Microsoft 365 支持）。旧版本或其他软件会自动改成“淡出”切换。
- 第1、3、4、6、10、13、16、17、19、26页有自动入场动画；第12页（五个角度小结）是点击出现，点5次出现5张卡片，第6次出现“画中情”。
- 封面上的“授课教师 / 授课班级”可以直接点开填写。

## 图文来源

课件和教案里的每一段引文、每一张图片都标了出处，课件最后一页是完整清单。主要来源：

1. 教材：人美版（2024）《艺术·美术》五年级上册第33—40页、前言与目录（国家中小学智慧教育平台电子教材）。作品图、教师范作、学生作品均取自教材第34—36页。
2. 《义务教育艺术课程标准（2022年版）》，教育部，第5—6页、第54—55页。
3. 新华社《中国乡土艺术焕发青春活力》（2026年8月30日电），含新华社记者王婧嫱摄影。
4. 科技日报《“大地绘彩——2025年农民画大展”在中国国家博物馆启幕》（2025年10月29日），含展览现场图片。
5. 中国非物质文化遗产网《安塞剪纸》；文化艺术报《“圪梁上的歌——安塞农民画作品展”明日开展》（2024年9月3日）；中华读书报《安塞的剪纸与绘画》（光明网，2000年7月12日）。
6. 课件自绘：印章、纹样示意图、《丰收曲》构图示意图、色彩比例条（对教材作品图片取色统计，比例为近似值）。
