## 导入短片

- 时长60秒，配乐是课件原创的五声音阶乐曲（FluidSynth 与 FluidR3_GM 音色库合成，锣声为程序合成），镜头切换、字幕都踩在鼓点上。
- 画面里的农民画作品与学生作品取自教材第34—36页，原样呈现；窑洞夜村、灯笼街、舞龙、旱船、腰鼓队、丰收、俯瞰村庄等节日场景全部用代码绘制（剪影、金色灯火、印刷网点的风格），没有使用 AI 生成的图片。
- 字体：马善政毛笔楷书（Ma Shan Zheng）、思源宋体（Noto Serif SC），均为 SIL OFL 1.1 开源字体。

## 课件使用提示

- 第2页：页面元素出现后，单击一次即从头播放短片（需要 PowerPoint 2016 及以上或 Microsoft 365，并连接音箱）。
- 正文字体是 Windows 自带的“微软雅黑”；书法标题是图片，在任何电脑上显示都一样。
- 全篇用“平滑”切换（PowerPoint 2019/Microsoft 365 支持），旧版本会自动改成“淡出”。
- 第1—26页有自动入场动画；第13页（五个角度小结）需要点击：点5次出现5栏，第6次出现“画中情”。
- 教学时间按40分钟分配：导入4分钟、任务一10分钟、任务二5分钟、构思与示范4分钟、创作12分钟、展评3分钟、拓展与小结2分钟。

## 版本说明

- 本课属于人美版（2024）全国版五年级上册（黄宗贤主编，人民美术出版社2026年7月第1版，ISBN 978-7-102-08964-5）。目录中第四单元《装点节日》共三课：农民画里的节日（第34页）、巧夺天工的民艺（第37页）、聚合至美庆佳节（第41页）。

## 图文来源

课件和教案里的每一段引文、每一张图片都标了出处，课件最后一页是完整清单。主要来源：

1. 教材：人美版（2024）《艺术·美术》五年级上册第33—40页、前言与目录（国家中小学智慧教育平台电子教材）。作品图、教师范作、学生作品均取自教材第34—36页。
2. 《义务教育艺术课程标准（2022年版）》，教育部，第5—6页、第54—55页。
3. 新华社《中国乡土艺术焕发青春活力》（2026年8月30日电），含新华社记者王婧嫱摄影。
4. 科技日报《“大地绘彩——2025年农民画大展”在中国国家博物馆启幕》（2025年10月29日），含展览现场图片。
5. 中国非物质文化遗产网《安塞剪纸》；文化艺术报《“圪梁上的歌——安塞农民画作品展”明日开展》（2024年9月3日）；中华读书报《安塞的剪纸与绘画》（光明网，2000年7月12日）。
6. 课件自绘：印章、纹样示意图、《丰收曲》构图示意图、颜料点（对教材作品图片取色统计，比例为近似值）、短片中的动画画面。
